### Task 2 — Verdict
- **Verdict**: HIGHLY USABLE (4 mechanisms, 4 slots)
- **Bullets (3–5)**:
  - Why this verdict + recency status: PASS (2025); the paper reports a built clinic system, a veterinarian test, and a survey of 102 staff, customers, and students, providing four concrete mechanisms and a quantified UX result.
  - Slots populated → Features 1–7 mapping: [Primary-Intervention-Mechanism] → Features 1, 2, 3; [Function-Feature-1-7] → Features 1, 2, 3; [Role-Gated-Value-Creation] → Features 2, 3; [Metric-Change-Target] → Features 1, 2.
  - Missing slots / metrics this source cannot cover: [System-Novelty] is thin; Features 4–7 are not evidenced; no latency, availability, error-rate, inventory, billing, AI-guidance, or automated-reminder metric is reported.
  - Panel use (what attack this citation deflects): deflects “the proposed system’s purpose is merely general digitalization” by showing a specific integrated record-and-appointment intervention and a 102-person UX acceptance result.
  - Transfer risk / caveat: the adoption application and animal-abuse screening workflow is quarantined outside CarePaws Features 1–7; the source also uses Waterfall, so its process evidence does not alter CarePaws’s locked Agile/DSR method. The 95% result is self-reported UX, not technical performance.
