- **Bullets**:

  - Slots populated → Features: [Input-Clinic-Baselines] → Features 1, 2, 3; [Process-Agile-DSR-Cycles] → Features 1–7; [Process-Inside-The-Arrows-Causal-Logic] → Features 1–7; [Output-Empirical-Usability-Baseline] → Features 1, 2, 4, 7.
  - Missing: [Input-ISO25010-Standards], [Process-RBAC-Engineering], an explicit permission matrix, clinic-workflow sample size, survey scale bounds, SD, and system-performance measures.
  - Panel use: Deflects the claim that a conceptual framework lacks a process-to-output evaluation link, but the mixed staff/customer/student sample prevents treating 95% as a CarePaws target.
  - Transfer caveat: The adoption workflow is outside Features 1–7, Waterfall departs from the locked Agile/DSR method, and the paper's later efficiency discussion conflicts with its earlier efficiency result.
