  - Slots populated → Features: [Empirical-System-Architecture] → Features 1, 2, 3; [Quantitative-Metric-Outcomes] → Features 1, 2, 3; [Acknowledged-Architectural-Flaws] → Features 1, 2.
  - Missing: [Hardware-Offline-Fallbacks] ([NOT STATED]); no implemented offline mode, database engine, deployment provider, latency, availability rate, or SUS result; connectivity is discussed for the predecessor Kreloses, not this build.

  - Caveat: The adoption workflow and free web-hosting dependency are outside CarePaws' locked feature set; use only the architecture, measurement, and resilience comparison.
